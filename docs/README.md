# Documentación de Vectra Cure

Este directorio concentra la documentación que no pertenece directamente a la
aplicación Flask ni a los scripts de base de datos. Cada carpeta responde a una
pregunta concreta para evitar documentos dispersos en la raíz del repositorio.

4. [Flujos de producto V2](product/prds/flujos-producto-v2-v1.0.md)
5. [Paquete de contexto para Google Stitch](design/stitch/README.md)

## Mapa de documentación

| Carpeta | Contenido |
| --- | --- |
| `architecture/` | Arquitectura técnica y decisiones de integración. |
| `design/` | Sistema visual y prompts de diseño para Google Stitch. |
| `guides/` | Manuales de operación y uso de la aplicación. |
| `implementation/` | Planes de implementación y supuestos técnicos. |
| `product/` | Flujos históricos, encuesta, sitemap y especificaciones vigentes. |
| `product/prds/` | Fuente de verdad del rediseño V2. |
| `research/` | Investigación UX, personas y hallazgos. |
| `reports/` | Entregables académicos en formato Word. |

## Convenciones

- Los documentos V2 dentro de `product/prds/` prevalecen cuando contradicen
  documentos anteriores.
- Los nombres se conservan para mantener trazabilidad con los entregables
  académicos originales.
- Los recursos de diseño para Stitch pertenecen a `design/stitch/`; no se
  mezclan con la aplicación ni con documentos de negocio.
- Las instrucciones de colaboración viven solo en `../FLUJO_DE_TRABAJO.md`.
